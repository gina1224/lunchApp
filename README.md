# 🍱 나이스 급식 알리미 (NEIS School Meals & Allergy Highlight App)

교육부 **나이스(NEIS) 교육정보 개방포털 공공데이터 API**를 직접 연동하여 전국의 초·중·고·특수학교 급식 식단을 실시간으로 조회하고, 사용자가 선택한 **알레르기 유발 성분을 식단표에서 강렬한 빨간색으로 강력하게 강조**해주는 스마트 웹 애플리케이션입니다.

---

## 🌟 주요 특징 및 구현 내용

### 1. 나이스(NEIS) 오픈 API 정식 연동
- **인증키**: `542d16543cef47afa8cab5704a845e12` (적용 완료)
- **학교 기본정보 API (`schoolInfo`)**: 전국 시·도 교육청 산하 초·중·고·특수학교 실시간 검색 지원
- **급식 식단정보 API (`mealServiceDietInfo`)**: 조식, 중식, 석식 메뉴, 칼로리, 영양성분, 원산지 정보 연동

### 2. 🛡️ 스마트 알레르기 안심 필터 & 강력한 빨간색 강조 (핵심 요구사항)
- **식약처 및 교육부 표준 19종 알레르기 유발 성분 완벽 지원**:
  1. 난류(달걀) / 2. 우유 / 3. 메밀 / 4. 땅콩 / 5. 대두(콩) / 6. 밀(밀가루)
  7. 고등어 / 8. 게 / 9. 새우 / 10. 돼지고기 / 11. 복숭아 / 12. 토마토
  13. 아황산류 / 14. 호두 / 15. 닭고기 / 16. 쇠고기(소고기) / 17. 오징어
  18. 조개류(굴, 전복, 홍합 등) / 19. 잣
- **알레르기 감지 알고리즘**:
  - 나이스 표준 요리명 뒤 번호 표기(예: `(1.5.6.)`, `(5.6.16.)`)를 정규표현식으로 정밀 파싱
  - 학교별 표기 누락에 대비한 핵심 식재료 키워드 2중 안전 검증
- **시각적 빨간색 강조 효과**:
  - **진하고 선명한 굵은 빨간색 글씨 (`#9f1239`, Bold 850)**
  - **위험 경고 빨간 테두리 (`2.5px solid #e11d48`) 및 펄스 글로우 애니메이션**
  - **알레르기 위험 뱃지 (`⚠️ 알레르기 주의: 난류(1), 우유(2)` 등 감지된 성분 직관적 표시)**
  - **상단 실시간 위험 요약 배너**: 오늘 식단 중 주의해야 할 메뉴 개수 및 성분을 한눈에 브리핑

### 3. 직관적인 사용자 경험 (UX/UI)
- **원클릭 학교 검색**: 학교 이름 입력 시 시도교육청 및 도로명 주소와 함께 빠른 선택 지원
- **최근 선택 학교 자동 저장 (`localStorage`)**: 재접속 시 이전 선택 학교와 알레르기 설정이 그대로 복원
- **날짜 탐색기**: 오늘, 이전날(◀), 다음날(▶) 및 캘린더 날짜 선택기를 통한 과거/미래 식단 조회
- **주간 식단 모아보기 (월~금)**: 한 주간의 점심 식단을 요일별로 모아서 보며 알레르기 성분 일괄 확인
- **상세 영양 & 원산지 팝업**: 탄수화물, 단백질, 칼슘 등 상세 영양성분 및 쌀, 쇠고기, 김치 원산지 정보 확인
- **식단 텍스트 복사**: 카카오톡이나 메시지로 오늘 식단을 바로 공유할 수 있는 원클릭 복사 기능

## 🚀 실행 방법

본 웹 앱은 외부 라이브러리 설치나 복잡한 빌드 과정이 필요 없는 **Zero-Dependency Pure HTML5 / CSS3 / Modern ES6 JavaScript**로 제작되었습니다.

### 방법 1. 브라우저에서 바로 열기
1. 파일 탐색기에서 프로젝트 폴더를 엽니다.
2. `index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 사파리(Safari), 웨일 등 즐겨 쓰는 브라우저에서 바로 실행합니다.

### 방법 2. 로컬 웹 서버로 열기 (권장)
VS Code의 `Live Server` 확장을 사용하거나, 터미널에서 로컬 서버를 실행하여 접속할 수 있습니다:
```bash
# Python이 설치되어 있는 경우:
python -m http.server 8080

# 브라우저에서 http://localhost:8080 접속
```
